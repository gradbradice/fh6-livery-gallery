## English

### Description

FH6 Livery Gallery is a convenient way to browse your Forza Horizon 6 livery collection without launching the game just to check it. The application reads save files directly from your disk, parses their binary format, and displays your collection as a gallery of preview cards. It supports search, grouping by manufacturer, author, and date, favorites, and custom tags.

The application provides a convenient way to browse your collection that is not available in the game itself. If you have hundreds of downloaded liveries and can no longer remember which one is where, this application is for you.

The following languages are currently supported: English, Japanese, German, Spanish, French, Italian, Korean, Portuguese, Russian, Simplified Chinese (ZH-CN), and Traditional Chinese (ZH-TW).
