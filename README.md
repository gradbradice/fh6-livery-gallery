## English

### Description

FH6 Livery Gallery lets you browse your Forza Horizon 6 livery collection without launching the game. The application reads your save files directly from disk, analyzes their binary format, and displays your collection as a gallery of preview cards. It supports search, sorting and grouping by manufacturer, author, and date, as well as favorites and custom tags.

Unlike the standard features available in the game, the application makes it easy to find and organize your liveries using different sorting and grouping criteria. If you have hundreds of downloaded liveries and can no longer remember where each one is, FH6 Livery Gallery helps you quickly find the livery you need.

The following languages are currently supported: English, Japanese, German, Spanish, French, Italian, Korean, Portuguese, Russian, Simplified Chinese (ZH-CN), and Traditional Chinese (ZH-TW).
